About Game

Procedural Audio Engine

Synthesizes 100% of game sounds at runtime using mathematical PCM sine-wave formulas—zero external sound files required.

Spin Deflection Physics

Rebound trajectory dynamically adjusts based on ball impact point on paddle surface and paddle velocity.

Interactive Power-Ups

Features + Grow (1.5x paddle size extension) and S Slow (resets ball speed) drops with active HUD timers.

Fullscreen & AI Modes

Supports native Fullscreen toggle (`F11`), Pause Menu (`P`/`ESC`), AI Difficulty levels (Easy/Medium/Hard), and highscore JSON saving.
